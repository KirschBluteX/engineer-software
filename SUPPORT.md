# Support

Engineer Software is maintained as an open-source, skills-only Codex plugin.

For reproducible defects, include the plugin version, Codex version, operating system, prompt,
expected route, observed route, and the smallest relevant repository fixture. Please remove
credentials, tokens, private source, and personal data before opening an issue.

- Bug reports and feature requests: <https://github.com/KirschBluteX/engineer-software/issues>
- Security reports: see [SECURITY.md](SECURITY.md)
